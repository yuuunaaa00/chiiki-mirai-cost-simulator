# 地域みらい留学 費用シミュレーター

地域みらい留学(https://c-mirai.jp/)の対象校について、「検討時にかかる費用」と「留学後にかかる費用」を概算でシミュレーションできる静的Webツールです。

公開ページ: https://yuuunaaa00.github.io/chiiki-mirai-cost-simulator/ (`docs/` フォルダをGitHub Pagesで公開)

仕様書: Googleドキュメント「費用・出口施策」(2026年10月更新版)

## データの取得方法(v1)

1. https://c-mirai.jp/schools の全ページ(page=1〜8)から、全189校のID・学校名を収集。
2. 各校の詳細ページ(`/schools/{id}`)をChromeブラウザ経由で取得し、「学費・生活費」セクションのテキストを抽出。
3. `scripts/parse_raw.py` で正規表現ベースの構造化を行い、以下を抽出:
   - 初年度経費(入学金・授業料・制服代等の内訳と合計)
   - 生活費(月額、住居費・食費・光熱費等の内訳と合計)
   - 居住タイプ(寮・シェアハウス・ホームステイ・一人暮らし等)ごとの説明文
4. `scripts/enrich_prefecture.py` で住所文字列から都道府県を判定し、距離計算用の概算座標(県庁所在地)を付与。


## 計算ロジック(仕様書 2026年10月版)

### 検討時の費用(志望校ごと)
- 前提: 親1人＋子1人(2人)、訪問2回(オープンスクール・受検)
- 往復交通費 = 片道運賃 × 2(往復) × 2人 × 2回
- 宿泊費 = 宿泊日数(日帰り/1泊/2泊) × 8,000円(1人1泊) × 2人 × 2回
- 受検の費用 = 2,200円(公立高校の受検料の目安)

### 留学後の費用
- 初年度の費用・月々の生活費: 各校の公表金額(未掲載・調整中の学校は「学校へお問い合わせください」と表示)
- 帰省費 = 片道運賃 × 2(往復) × 帰省回数(GW/夏休み/冬休み/春休みから1〜4回) ※1人分
- お小遣い(月) = 10,000円 ＋ 750円 × 出ない食事数(月)
  - 1か月 = 30日×3食 = 90食(平日22日・土曜4日・日曜4日)として、出ない食事数 = 90 − 提供される食数
  - 例: 平日のみ3食 → 90−66 = 24食、朝夕のみ毎日 → 90−60 = 30食
  - 750円は、自炊の想定額300円と外食の想定額1,200円の中央値
  - 各校の提供条件は `scripts/meal_provision.py` に判定結果として記録(公表資料に記載がない学校は加算せず、学校への確認事項に表示)
- 1年目の合計(目安) = 初年度の費用 ＋ (月々の生活費 ＋ お小遣い) × 12か月 ＋ 帰省費

### 片道運賃
都道府県庁所在地間の直線距離を、JR在来線の営業キロ別運賃の目安表に当てはめた概算です。

## v1の既知の制約(今後の改善候補)

- **生活費の「合計0円」表示について**: 学校側のページ自体で金額が「調整中」「未定」となっているケースがそのまま反映されています(パースの不具合ではなく元データの状態です)。v2以降、学校への確認や更新チェックの仕組みを検討。
- **住居タイプが複数ある学校**: 生活費の合計金額は学校ページに記載された代表値であり、住居タイプ(寮/シェアハウス/ホームステイ等)ごとの金額差を完全には反映していません。各住居タイプの説明文(備考)はシミュレーター上に表示されますが、金額の自動反映はv2以降の課題です。
- **距離・交通費の計算**: 各都道府県の県庁所在地間の直線距離と、JR在来線運賃表(概算)をもとにした非常に簡易なロジックです。新幹線・飛行機を使う場合や、実際の乗換経路とは異なります。v2では駅すぱあと等の経路探索APIとの連携を検討可能ですが、その場合は別途APIキー管理・利用料が発生します。
- **食事の提供条件**: 189校中、公表資料から提供条件(何食・何曜日)を判定できたのは77校です。残りの学校は加算せず「学校への確認事項」に表示しています。学校から情報を集め、`scripts/meal_provision.py` に追記すれば反映できます。
- **受検料**: 公立高校の一般的な目安(2,200円)を一律で使用しています。学校・自治体により異なります。

## データの更新方法

1. `data/schools_master.tsv` を最新の学校一覧で更新(必要に応じてChromeブラウザ等で再取得)。
2. 各校ページから学費・生活費テキストを再取得し、`data/raw_dump_part*.txt` に保存。
3. `python3 scripts/parse_raw.py` を実行して `data/schools_cost_data.json` を再生成。
4. `python3 scripts/enrich_prefecture.py` を実行して都道府県情報を付与。
5. 食事提供条件を見直す場合は `scripts/meal_provision.py` を編集して実行。
6. `python3 scripts/build_site_data.py` で `docs/data/schools.json` を再生成。
7. `docs/` の内容をGitHubにpushすれば、GitHub Pagesで自動的に反映されます。
