# 地域みらい留学 費用シミュレーター

地域みらい留学(https://c-mirai.jp/)の対象校について、「検討時にかかる費用」と「留学後にかかる費用」を概算でシミュレーションできる静的Webツールです。

公開ページ: https://yuuunaaa00.github.io/chiiki-mirai-cost-simulator/ (`docs/` フォルダをGitHub Pagesで公開)

仕様書: Googleドキュメント「費用・出口施策」(2026年10月更新版)

## ディレクトリ構成

```
simulator/

│   ├── raw_dump_part*.txt     # 各校ページから抽出した学費・生活費の生テキスト

│   ├── prefecture_centroids.json
│   ├── school_locations.json  # 各校の緯度経度(国土地理院「地理院地図」住所検索で町域を検索)
│   ├── airports.json          # 定期便のある空港の一覧(OurAirports のデータから作成)
```

## データの取得方法(v1)

1. https://c-mirai.jp/schools の全ページ(page=1〜8)から、全189校のID・学校名を収集。
2. 各校の詳細ページ(`/schools/{id}`)をChromeブラウザ経由で取得し、「学費・生活費」セクションのテキストを抽出。
3. `scripts/parse_raw.py` で正規表現ベースの構造化を行い、以下を抽出:
   - 初年度経費(入学金・授業料・制服代等の内訳と合計)
   - 生活費(月額、住居費・食費・光熱費等の内訳と合計)
   - 居住タイプ(寮・シェアハウス・ホームステイ・一人暮らし等)ごとの説明文
4. `scripts/enrich_prefecture.py` で住所文字列から都道府県を判定し、距離計算用の概算座標(県庁所在地)を付与。


## 計算ロジック(仕様書 2026年10月版)

### 検討時の費用(志望校ごと)
- 前提: 親1人＋子1人(2人)、訪問2回(現地訪問(オープンスクールなど)・受検)
- 交通手段(車・飛行機・JR)と宿泊日数(日帰り・1泊・2泊)は、学校ごとに選ぶ
  - JR: 1人片道運賃 × 往復 × 2人 × 2回
  - 飛行機: (航空券 ＋ 行き先の空港から学校までのJR運賃) × 往復 × 2人 × 2回。自宅から空港までは含まない
    - 航空券(片道) = 空港間の直線距離 × 15.3円(国内線の旅客1人1kmあたりの運賃収入。国土交通省「特定本邦航空運送事業者に関する航空輸送サービスに係る情報」2024年度・主要航空会社平均)
    - お住まいの地域の最寄り空港は利用者が選び、行き先の最寄り空港は学校の位置から自動で決める(海をまたがない空港から選ぶ。島の学校は島の空港)
  - 車: (高速代 ＋ ガソリン代) × 往復 × 2回 ※車1台
    - 道路の距離 = 直線距離 × 1.25(仮定)
    - 高速代: NEXCOの普通車の料金の計算方法(税込): 150円 ＋ 24.6円/km、100km超〜200kmの部分は25%引き、200km超の部分は30%引き(10円単位で四捨五入)
    - ガソリン代 = 道路の距離 ÷ 13.3km/L × 170円/L
      - 13.3km/L: 自家用乗用車(ガソリン)の実際の平均燃費(国土交通省「自動車燃料消費量調査」2025年度。燃料消費量と走行キロから算出)
      - 170円/L: レギュラーガソリンの全国平均価格(資源エネルギー庁「石油製品価格調査」2026年8月17日 169.8円)
    - 島の学校、北海道・沖縄県との行き来は車を選べない(フェリーが必要なため)
- 宿泊費 = 14,463円(1室) × 宿泊日数(日帰り/1泊/2泊) × 2回 ※親子で1室
  - 14,463円: 上場ビジネスホテル9ブランドの平均客室単価(東京商工リサーチ 2025年度)
- 受検の費用 = 2,200円(公立高校の受検料の目安)
- お住まいの地域の位置は都道府県庁所在地、学校の位置は各校の住所(町域)の緯度経度を使う

### 留学後の費用
- 初年度の費用・月々の生活費: 各校の公表金額(未掲載・調整中の学校は「学校へお問い合わせください」と表示)
- 帰省費: 交通手段(車・飛行機・JR)を選び、帰省回数(GW/夏休み/冬休み/春休みから1〜4回)を掛ける
  - JR・飛行機: 生徒1人分の往復運賃 × 帰省回数(飛行機は空港から学校までのJR運賃を含む)
  - 車: 車1台の往復1回分(高速代＋ガソリン代) × 帰省回数
  - 各交通手段の計算方法は「検討時の費用」と同じ
- お小遣い(月) = 10,000円 ＋ 750円 × 出ない食事数(月)
  - 1か月 = 30日×3食 = 90食(平日22日・土曜4日・日曜4日)として、出ない食事数 = 90 − 提供される食数
  - 例: 平日のみ3食 → 90−66 = 24食、朝夕のみ毎日 → 90−60 = 30食
  - 750円は、自炊の想定額300円と外食の想定額1,200円の中央値
  - 各校の提供条件は `scripts/meal_provision.py` に判定結果として記録(公表資料に記載がない学校は加算せず、学校への確認事項に表示)
- 1年目の合計(目安) = 初年度の費用 ＋ (月々の生活費 ＋ お小遣い) × 12か月 ＋ 帰省費

### 片道運賃(JR)
お住まいの都道府県の県庁所在地から学校までの直線距離を、JR在来線の営業キロ別運賃の目安表に当てはめた概算です。

## 入力内容の記録(Googleスプレッドシート)

「費用を計算する」ボタンが押されるたびに、次の内容をスプレッドシートに1行ずつ記録します。氏名・メールアドレスなど、個人を特定できる情報は記録しません。

| 列 | 内容 |
|---|---|
| 受信日時 / 種類 | 記録した日時、「検討時」か「留学後」か |
| 居住地 | 選ばれた都道府県 |
| 学校1〜3 / 交通手段1〜3 / 宿泊日数1〜3 | 選ばれた学校・交通手段・宿泊日数(留学後は学校1と交通手段1のみ) |
| 最寄り空港 | 飛行機を選んだときの、お住まいの地域の最寄り空港 |
| 帰省時期 | 留学後のみ |
| 合計金額 | 計算結果の合計 |
| セッションID | ページを開くたびに作る8文字のランダムな文字(同じ人の連続した計算をまとめて見るため。保存はしない) |

### 設定方法

1. Googleドライブで、記録用のスプレッドシートを新しく作る
2. スプレッドシートの [拡張機能] > [Apps Script] を開き、`gas/Code.gs` の内容を貼り付けて保存する
3. [デプロイ] > [新しいデプロイ] で種類「ウェブアプリ」を選び、次のように設定してデプロイする
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 初回はGoogleアカウントの権限の確認が表示されるので、許可する
5. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/.../exec`)を、`docs/config.js` の `logEndpoint` に設定する
6. シートは初回の記録時に「記録」という名前で自動作成される

`gas/Code.gs` を修正したときは、[デプロイ] > [デプロイを管理] から新しいバージョンとしてデプロイし直してください(URLは変わりません)。

## v1の既知の制約(今後の改善候補)

- **生活費の「合計0円」表示について**: 学校側のページ自体で金額が「調整中」「未定」となっているケースがそのまま反映されています(パースの不具合ではなく元データの状態です)。v2以降、学校への確認や更新チェックの仕組みを検討。
- **住居タイプが複数ある学校**: 生活費の合計金額は学校ページに記載された代表値であり、住居タイプ(寮/シェアハウス/ホームステイ等)ごとの金額差を完全には反映していません。各住居タイプの説明文(備考)はシミュレーター上に表示されますが、金額の自動反映はv2以降の課題です。
- **距離・交通費の計算**: 直線距離をもとにした簡易なロジックです。実際の経路・乗換、新幹線・特急、直行便の有無、時期による運賃の変動は反映していません。航空券は距離に比例する計算のため、短い路線は実際より安く出やすいです。経路探索APIとの連携は、APIキー管理・利用料が別途発生します。
- **ガソリン価格**: `docs/app.js` の `GAS_PRICE` に固定値(170円/L)で入れています。大きく変わったときは更新してください。
- **食事の提供条件**: 189校中、公表資料から提供条件(何食・何曜日)を判定できたのは77校です。残りの学校は加算せず「学校への確認事項」に表示しています。学校から情報を集め、`scripts/meal_provision.py` に追記すれば反映できます。
- **受検料**: 公立高校の一般的な目安(2,200円)を一律で使用しています。学校・自治体により異なります。

## データの更新方法

1. `data/schools_master.tsv` を最新の学校一覧で更新(必要に応じてChromeブラウザ等で再取得)。
2. 各校ページから学費・生活費テキストを再取得し、`data/raw_dump_part*.txt` に保存。
3. `python3 scripts/parse_raw.py` を実行して `data/schools_cost_data.json` を再生成。
4. `python3 scripts/enrich_prefecture.py` を実行して都道府県情報を付与。
5. 食事提供条件を見直す場合は `scripts/meal_provision.py` を編集して実行。
6. `python3 scripts/build_site_data.py` で `docs/data/schools.json` を再生成。
7. `docs/` の内容をGitHubにpushすれば、GitHub Pagesで自動的に反映されます。
